# lane: x25519

X25519 (RFC 7748): the key exchange chaki's TLS offers. TweetNaCl's 16 limbs of 16 bits are
the model.

## Files you own

`lib/chaki/x25519.bend`, `test/chaki_x25519_check.bend`.

## API (exact)

```python
# the 32-byte shared value of a 32-byte scalar and a 32-byte u-coordinate (scalar clamped,
# u's top bit masked, as RFC 7748 §5 says)
def x25519(scalar: List<&2, U32>, u: List<&2, U32>) -> List<&2, U32>
# x25519(scalar, 9)
def public(scalar: List<&2, U32>) -> List<&2, U32>
```

## How

- Field elements mod 2^255-19 as 16 limbs of 16 bits in a constructor (or a fixed list).
  U32.mul keeps only 32 bits, so a 16x16 product fits, but sums of products don't: split
  each product into high and low halves as you accumulate, then carry.
- A Montgomery ladder of 255 steps with a constant-time conditional swap (masks, no branch on
  secret bits). Inversion by exponentiation to p-2.
- One step of the ladder is a handful of field multiplications; keep each in its own small
  def. Native builds reject wide defs.

public keys and their shared secret, computed from both sides). Report the time for one
