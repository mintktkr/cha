# Getting help

- **How do I…?** Start with `cha help` and the [agent skill](skills/cha/SKILL.md), which lists every command and flag. [docs/how.md](docs/how.md) shows how a command flows.
- **Something's wrong or missing?** [Open an issue](https://github.com/mintktkr/cha/issues/new/choose). Questions are fine there too.
- **A security problem?** See [SECURITY.md](SECURITY.md), not the issue tracker.
- **Bend itself?** The Bend community lives on [Discord](https://discord.bend-lang.com) and [r/bendlang](https://www.reddit.com/r/bendlang).
